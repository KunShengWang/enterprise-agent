# AWS synthetic procurement data

来源：`aws-samples/sample-multi-agent-procure-to-pay`

本目录仅保留第一阶段采购寻源 MVP 使用的三份基础数据：供应商、商品组和商品。
数据为 synthetic and fabricated for demonstration，来源仓库采用 MIT No Attribution
许可证；本项目不把它们当作生产供应商或实时报价数据。

本目录是 AWS Base Dataset。workstation 的供应商专属报价、交期和规格来自
`data/procurement/scenarios/` 下明确配置的 project-specific scenario fixture，
不应把 fixture 报价描述为 AWS 原始数据。
